# v0.0.1-alpha.228

## English

### Fixed

- Fixed saving a user-defined Scan Workflow from the composition builder. Saving a draft that contains engines or unused empty stages no longer fails with an HTTP 400 error, and a rejected save keeps the draft visible and explains the failure instead of failing silently.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.227...v0.0.1-alpha.228

### 修复

- 修复在编排页保存自定义扫描工作流失败的问题。草稿包含引擎或未使用的空阶段时不再返回 HTTP 400 错误；保存失败时会保留当前草稿并提示失败原因，不再静默失败。

# v0.0.1-alpha.184

## English

### Added

- Added catalog-driven duration units and a compact duration wheel editor for scan configuration.

### Improved

- Added optional Cloudflare image acceleration for public deployments.
- Improved upgrade diagnostics and made the upgrade view recover more reliably from stale state.
- Improved wordlist details by grouping statistics with their resource metadata.

### Fixed

- Preserved configured API key settings when provider fields are updated.
- Restored the login access-help text in the login experience.
- Prevented development mock behavior from being enabled in production.
- Kept legacy update candidates usable when release notes are absent, while preserving validation when notes are provided.
- Allowed directory scan results to represent an explicitly empty content type.

### Security

- Hardened upgrade override permissions and improved recovery from interrupted upgrades.

### Documentation

- Documented public endpoints, HTTPS ports, and the Cloudflare acceleration installation option.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.183...v0.0.1-alpha.184

## 简体中文

### 新增

- 为扫描配置增加由目录驱动的时长单位和紧凑的时长滚轮编辑器。

### 改进

- 为公开部署增加可选的 Cloudflare 镜像加速。
- 改进升级诊断，并提升升级界面对过期状态的恢复可靠性。
- 改进字典详情，将统计信息与资源元数据分组展示。

### 修复

- 更新提供商字段时保留已配置的 API 密钥设置。
- 恢复登录体验中的访问帮助文案。
- 阻止开发用模拟行为在生产环境启用。
- 在缺少发布说明时仍支持旧版本更新候选，同时保留发布说明存在时的校验。
- 允许目录扫描结果表示明确为空的内容类型。

### 安全

- 强化升级覆盖操作的权限控制，并改进中断升级后的恢复。

### 文档

- 补充公网端点、HTTPS 端口和 Cloudflare 加速安装选项的说明。

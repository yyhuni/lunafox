# v0.0.1-alpha.192

## English

### Improved

- Improved reliability when publishing verified Runtime images and Engine packages.
- Improved public release compatibility by accepting one verified legacy workflow record while keeping unknown history rejected.

### Fixed

- Fixed plain ./install.sh reusing a previous Cloudflare acceleration setting. An unflagged install now returns to the default image transport while keeping deployment data, and Cloudflare acceleration requires explicit re-enablement.

### Documentation

- Documented the recovery status of the previous release.
- Recorded merged-tree verification for the release recovery audit.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.190...v0.0.1-alpha.192

## 简体中文

### 改进

- 提高了经验证 Runtime 镜像和 Engine 包发布的可靠性。
- 通过接受一条已核验的旧 workflow 记录并继续拒绝未知历史，提升了公开发布兼容性。

### 修复

- 修复了不带参数的 ./install.sh 复用先前 Cloudflare 加速设置的问题。无参数安装现在会在保留部署数据的同时恢复默认镜像传输，重新启用 Cloudflare 加速必须显式执行。

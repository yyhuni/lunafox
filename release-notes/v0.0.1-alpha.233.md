# v0.0.1-alpha.233

## English

### Improved

- Moved MCP connection setup from the top bar to a dedicated sidebar page, with an automatic connection animation and client-native configurations for Claude Code, Cursor, Codex and VS Code. Existing one-time key and rotation behavior is preserved. Improved collapsed sidebar icon alignment and hover menus, removed sidebar tooltip arrows, and made toast notifications compact. For installation and upgrades, follow the [public deployment guide](https://github.com/yyhuni/lunafox/blob/main/docs/public-deployment.md) and this release page.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.232...v0.0.1-alpha.233

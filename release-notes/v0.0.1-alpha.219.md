# v0.0.1-alpha.219

## English

### Added

- Added related screenshot summaries to Website search results.
- Added full result export for global Website and Endpoint searches with streamed CSV downloads.

### Improved

- Improved response evidence scrolling for long responses.
- Improved scan workflow editing with a docked engine library and reachable YAML actions.
- Unified scrollbar visibility across the interface.
- Removed idle scrollbar track backgrounds for a cleaner interface.
- Improved stopping large scan selections by batching requests and reporting partial failures.
- Improved port scan reliability by scaling time budgets with candidate counts.
- Refined notification settings controls with quieter icons and compact actions.
- Improved notification delivery testing by pairing the test action with its credential input.

### Fixed

- Fixed virtualized tables losing row visibility while scrolling.
- Fixed public release validation for releases that rebuild only selected Engines.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.217...v0.0.1-alpha.219

## 简体中文

### 新增

- 为 Website 搜索结果新增关联截图摘要。
- 为全局 Website 和 Endpoint 搜索新增全量结果导出，使用流式 CSV 下载。

### 改进

- 改进长响应的响应证据滚动体验。
- 改进扫描工作流编辑体验，提供停靠式引擎库并确保 YAML 操作可访问。
- 统一界面中的滚动条可见性。
- 移除空闲状态的滚动条轨道背景，让界面更简洁。
- 改进大批量扫描选择的停止操作，分批发送请求并报告部分失败。
- 改进端口扫描稳定性，根据候选数量调整时间预算。
- 优化通知设置控件，采用更克制的图标和更紧凑的操作。
- 改进通知投递测试，将测试操作与凭据输入放在一起。

### 修复

- 修复虚拟化表格滚动时行内容不可见的问题。
- 修复仅重建选定引擎的公开发布校验。

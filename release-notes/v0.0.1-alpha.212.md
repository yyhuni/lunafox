# v0.0.1-alpha.212

## English

### Added

- Website Discovery, Directory Scan, Nuclei vulnerability scan, URL Collection, and Screenshot can send custom HTTP headers from the scan configuration, including Cookie and Authorization. Screenshot capture includes every configured header on the page request.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.209...v0.0.1-alpha.212

### 新增

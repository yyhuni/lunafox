# v0.0.1-alpha.200

## English

### Added

- Added a 24-hour schedule horizon projection to the scheduled-scan overview, with a distribution axis showing when enabled scans fire across the next day.
- Added a read-only run history for scheduled scans: the management-list handoff metric now opens a run-history tab showing every retained trigger with its status, failure cause, bounded diagnostics, and retry progress, and triggers that stay unsettled are surfaced as suspected-stuck.

### Improved

- Refined dropdown menus opened from compact inline triggers such as table column headers with a matching compact density, so the opened menu no longer reads a size larger than the control that opened it.

### Fixed

- Aligned dense table row-action controls with the 28px compact control tier so action sizing stays consistent across data tables.

### Documentation

- Documented the 24-hour schedule horizon projection as a maintained specification.
- Documented the published legacy preheat-manifest exemption as a maintained specification.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.199...v0.0.1-alpha.200

## 简体中文

### 新增

- 定时扫描总览新增未来 24 小时调度时间轴投影，并以分布轴展示启用任务在接下来一天内的触发时间。
- 定时扫描新增只读调度记录：管理列表的调度结果现在可以直接打开调度记录页签，查看保留期内每次触发的状态、失败原因、诊断信息与重试进度；长时间未结算的触发会被标记为疑似卡住。

### 改进

- 优化由紧凑内联触发器（如表格列头）打开的下拉菜单，采用匹配的紧凑密度，菜单不再显得比触发它的控件大一号。

### 修复

- 对齐紧凑表格的行操作控件与 28px 紧凑控件层级，使各数据表格中的操作尺寸保持一致。

### 文档

- 将未来 24 小时调度时间轴投影沉淀为维护规范。
- 将已发布旧版预热清单的豁免规则沉淀为维护规范。

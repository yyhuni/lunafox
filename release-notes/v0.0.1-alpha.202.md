# v0.0.1-alpha.202

## English

### Fixed

- Fixed disabled scheduled scans still showing a stale past next-execution time when the database was written by older builds; forward migration 000006 now clears the retained cursor of every disabled schedule in one idempotent pass.
- Fixed row action dropdown menus freezing at the top-left corner of the page when their anchor row became unavailable; the menu now closes itself and can be reopened, and the UI foundation moves from Base UI 1.7.0 to 1.8.0.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.201...v0.0.1-alpha.202

## 简体中文

### 修复

- 修复了旧版本构建写入的数据库中，已禁用的定时扫描仍显示过期的下次执行时间的问题；前向迁移 000006 现在以一次幂等清理清除所有禁用任务的残留游标。
- 修复了锚点行不可用时，行尾操作下拉菜单冻结在页面左上角的问题；菜单现在会自动收起并可重新打开，UI 基础组件同时从 Base UI 1.7.0 升级到 1.8.0。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.201...v0.0.1-alpha.202

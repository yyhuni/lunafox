# v0.0.1-alpha.224

## English

### Added

- Deployments can choose independent custom HTTPS OCI registries for product images and engine packages. Internal mirrors must preserve repository paths, artifact contents, and signatures; signature and digest verification remain enforced.

### Improved

- URL Collection and Website Discovery preserve the host reported by HTTPX even when it differs from the URL, and retain nonstandard, negative, or large status-code and content-length observations as signed 64-bit values. Response bodies and headers have NUL removed and are safely truncated before submission. Both engines now use v2 result contracts. Update their engine packages together with the server: submissions from older v1 packages are no longer accepted.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.222...v0.0.1-alpha.224

## 简体中文

### 新增

- 部署时可为产品镜像和引擎包分别配置自定义 HTTPS OCI 仓库。内部镜像仓库需要保留原有仓库路径、制品内容和签名，系统仍会校验签名与摘要。

### 改进

- URL Collection 和 Website Discovery 会保留 HTTPX 上报的 host，即使它与 URL 不同；非标准、负数或较大的状态码和内容长度也会按有符号 64 位数值保存。响应正文与响应头会在提交前去除 NUL 并安全截断。这两个引擎现使用 v2 结果契约。请随服务端一起更新它们的引擎包，旧 v1 引擎包提交的结果将不再被接收。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.222...v0.0.1-alpha.224

# v0.0.1-alpha.206

## English

### Fixed

- Unread notifications now use a compact dot instead of an oversized numeric badge.
- The scheduled scan edit drawer no longer leaves an extra gap between the header and its tabs, and the tab layout matches the detail drawer.
- Scheduled scans dispatch again. A database error was stopping every scheduler pass before a scan could start, including a retry after a transient handoff failure.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.205...v0.0.1-alpha.206

## 简体中文

### 修复

- 未读通知改为紧凑圆点，不再使用过大的数字角标。
- 定时扫描编辑抽屉的标题和页签之间不再留出多余空隙，页签布局与详情抽屉一致。
- 定时扫描可以重新调度。此前数据库错误会让每一轮调度在扫描开始前失败，瞬时交接失败后的重试也同样无法开始。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.205...v0.0.1-alpha.206

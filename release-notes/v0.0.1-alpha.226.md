# v0.0.1-alpha.226

## English

### Improved

- Reworked the overview asset distribution so every asset type keeps the same visual weight, with its count, share, seven-day change, and a dedicated trend line instead of a shared bar length.
- The Agent capacity upgrade guidance now lists multiple contribution routes, such as sponsorship, bug reports, and engine optimization work, that can be recognized when requesting a Key from the author.

### Fixed

- Fixed the first Blacklist policy save on fresh deployments or newly created Targets failing with a false conflict error.

### Documentation

- Release notes for migration-bearing versions now state the manual upgrade path and backup requirement in both languages.
- Reworked the public README with updated product screenshots, a streamlined installation flow, built-in engine coverage, and clearer platform capability tables, and removed obsolete lineage and architecture sections.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.225...v0.0.1-alpha.226

## 简体中文

### 改进

- 重构了总览页的资产分布：各资产类型改为等权展示，分别显示数量、占比、近七天变化和独立趋势线，不再共用同一条柱形长度。
- Agent 扩容授权说明现在列出多种贡献途径（如赞助、提交问题、参与引擎优化等），均可作为联系作者获取 Key 的依据。

### 修复

- 修复全新部署或新建目标首次保存黑名单策略时误报冲突错误的问题。

### 文档

- 包含数据库迁移的版本说明现在会在中英文两节写明手动升级步骤与备份要求。
- 重写了公开 README：更新产品截图、精简安装流程、说明内置引擎与平台能力，并移除过时的来源与架构章节。

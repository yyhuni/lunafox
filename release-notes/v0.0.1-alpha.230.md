# v0.0.1-alpha.230

## English

### Added

- Global asset search now supports filtering Website and Endpoint results by organization name. Contains and exact matching can be combined with existing fields and AND/OR conditions.

### Improved

- Clarified the engine catalog labels for resources required by each engine, so users can distinguish external dependencies and runtime artifacts from compute capacity.
- Refined sidebar navigation icon sizing to keep dense navigation visually balanced in expanded and collapsed layouts.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.229...v0.0.1-alpha.230

## 简体中文

### 新增

- 全局资产搜索现在支持按组织名称筛选 Website 和 Endpoint 结果。包含匹配和精确匹配可以与现有字段及 AND/OR 条件组合使用。

### 改进

- 明确引擎目录中各引擎所需资源的说明，帮助用户区分外部依赖与运行时制品和计算容量。
- 调整侧边栏导航图标尺寸，让展开和折叠布局下的密集导航保持更好的视觉平衡。

# v0.0.1-alpha.176

## English

### Improved

- Scheduled scans now retain a selected time zone and run at the configured local time, including daylight-saving transitions. Release notes are now available from the update experience, with links to the corresponding public release. Improved update and release reliability through stronger component validation and more resilient delivery of required runtime images. Improved table actions and contextual guidance for targets and organizations, with more consistent tooltips and clearer deletion feedback. Updates are now offered only when the deployed components actually require a change. Fixed an issue that could make a valid scan configuration appear invalid after returning to the configuration step. Fixed validation of batch target imports so invalid entries are reported before the import is submitted. Clarified administrator access and deployment configuration guidance, including changes that require recreating services.
- Adjusted upgrade component naming without changing how updates are applied.

### Fixed

- Fixed release assembly so the signed Agent programs are included in the published update.

## 简体中文

### 改进

- 计划扫描现在会保存所选时区，并按配置的本地时间运行，且会正确处理夏令时切换。更新界面现在可查看发布说明，并可跳转到对应的公开版本页面。通过更严格的组件校验和更可靠的所需运行时镜像交付，提升了更新与发布的可靠性。改进了目标和组织的表格操作与上下文指引，并提供更一致的提示和更清晰的删除反馈。现在仅在已部署组件确实需要变更时才会提供更新。修复了返回配置步骤后有效扫描配置可能被误判为无效的问题。修复了批量导入目标的校验问题，现在会在提交导入前报告无效条目。澄清了管理员访问和部署配置指引，包括需要重新创建服务的变更。
- 调整了升级组件的命名，更新的实际行为保持不变。

# v0.0.1-alpha.217

## English

### Added

- Global asset search can match stored response headers on websites and endpoints. One equals sign is a case-insensitive contains match of at least 3 characters, and two equals signs require the entire stored header text to match exactly.
- The notification drawer can mark one unread item as read, and marking every notification read remains available.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.216...v0.0.1-alpha.217

## 简体中文

### 新增

- 全局资产搜索可以匹配网站和端点上已保存的响应头。一个等号表示至少包含 3 个字符的不区分大小写匹配，两个等号则要求整段已保存响应头文本完全一致。
- 通知抽屉可以把单条未读通知标记为已读，同时仍可一次把全部通知标记为已读。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.216...v0.0.1-alpha.217

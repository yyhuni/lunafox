# v0.0.1-alpha.180

## English

### Added

- Added an optional Cloudflare-accelerated image download path for root installations, centralized resource help on the Targets and Organizations pages, and fixed empty wordlist tags after reload.
- Added a copyable AIP resource name to Wordlist details.

### Improved

- Improved release reliability by keeping maintenance-only note deliveries out of product changelogs and strengthening installer reference validation.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.176...v0.0.1-alpha.180

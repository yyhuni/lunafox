# v0.0.1-alpha.203

## English

### Fixed

- Fixed scheduled scans silently stopping after an upgrade attempt that did not replace the server: any upgrade that failed before or during host handoff (failed preparation, rejected handoff, a host that disappeared mid-upgrade, or a stopped upgrade) used to leave the scheduler paused until a manual restart; the pause is now released automatically whenever an upgrade ends while the server keeps running, so schedules such as every-minute scans resume on their own.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.202...v0.0.1-alpha.203

## 简体中文

### 修复

- 修复了升级尝试未能替换服务端后定时扫描静默停摆的问题：任何在宿主机交接前或交接中失败的升级（准备失败、交接未被接受、升级中宿主机失联或升级被停止）此前都会让调度器保持暂停，直到手动重启才恢复；现在只要升级在服务端继续运行的情况下结束，就会自动释放调度暂停，每分钟等调度计划会自行恢复执行。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.202...v0.0.1-alpha.203

# v0.0.1-alpha.186

## English

### Added

- Added catalog-driven duration units and a compact duration wheel editor for scan configuration.
- Added clearer global asset search guidance with localized diagnostics and syntax examples.
- Added installation-time preheating for the current release's Engine Runtime and selected service images, with verified retries and recovery diagnostics.

### Improved

- Added optional Cloudflare-accelerated image delivery for public deployments.
- Improved upgrade diagnostics, activity visibility, and recovery from stale local state.
- Improved wordlist details by grouping statistics with their resource metadata.
- Improved upgrade migration handling by detecting and validating release boundaries automatically.

### Fixed

- Preserved configured API key settings when provider fields are updated.
- Restored access-help guidance in the login experience.
- Kept legacy update candidates usable when release notes are absent while validating notes when they are provided.
- Allowed directory scan results to represent an explicitly empty content type.
- Preserved edited default wordlists across restarts while retaining strict state validation.

### Security

- Prevented development mock behavior from being enabled in production.
- Hardened upgrade override permissions and recovery from interrupted upgrades.

### Documentation

- Documented public endpoint, HTTPS port, and Cloudflare acceleration installation options.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.183...v0.0.1-alpha.186

## 简体中文

### 新增

- 为扫描配置增加由目录驱动的时长单位和紧凑的时长滚轮编辑器。
- 增加更清晰的全局资产搜索指引、本地化诊断和语法示例。
- 增加安装阶段对当前版本 Engine Runtime 和选定服务镜像的预热，并提供经过校验的重试与恢复诊断。

### 改进

- 为公开部署增加可选的 Cloudflare 镜像加速。
- 改进升级诊断和活动可见性，并提升从过期本地状态恢复的可靠性。
- 改进字典详情，将统计信息与资源元数据分组展示。
- 改进升级迁移处理，自动检测并校验发布边界。

### 修复

- 更新提供商字段时保留已配置的 API 密钥设置。
- 恢复登录体验中的访问帮助说明。
- 在缺少发布说明时仍支持旧版本更新候选，同时在提供说明时继续校验其内容。
- 允许目录扫描结果表示明确为空的内容类型。
- 重启后保留已编辑的默认字典，同时继续执行严格的状态校验。

### 安全

- 阻止开发用模拟行为在生产环境启用。
- 强化升级覆盖操作的权限控制，并改进中断升级后的恢复。

### 文档

- 补充公网端点、HTTPS 端口和 Cloudflare 加速安装选项的说明。

# v0.0.1-alpha.207

## English

### Fixed

- A new installation keeps the documented database profile setting. An upgrade from that installation accepts the setting instead of failing its preflight check before any service is replaced, and a preparation failure now finishes on the upgrade page with a retry instead of staying in progress.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.206...v0.0.1-alpha.207

## 简体中文

### 修复

- 新安装会保留文档中的数据库配置。从该安装发起的升级会接受这项配置，而不会在替换任何服务之前的预检查中失败；如果准备阶段失败，升级页面会显示失败结果并可以重试，而不会一直停留在进行中。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.206...v0.0.1-alpha.207

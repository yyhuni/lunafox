# v0.0.1-alpha.213

## English

### Added

- Website Discovery, Directory Scan, Nuclei vulnerability scan, URL Collection, and Screenshot can send custom HTTP headers from the scan configuration, including Cookie and Authorization. Screenshot capture includes every configured header on the page request.

### Fixed

- Screenshot capture checks that every configured HTTP header reaches the page before that image is published.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.209...v0.0.1-alpha.213

## 简体中文

### 新增

- 站点发现、目录扫描、Nuclei 漏洞扫描、URL 收集和网页截图可以在扫描配置里发送自定义 HTTP 请求头，包括 Cookie 和 Authorization。网页截图会把每一条已配置的请求头带在页面请求上。

### 修复

- 网页截图会在镜像发布前确认每一条已配置的 HTTP 请求头都会到达页面。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.209...v0.0.1-alpha.213

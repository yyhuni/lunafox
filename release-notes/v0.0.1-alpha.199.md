# v0.0.1-alpha.199

## English

### Added

- Added stop and batch-stop investigation scan tools to the MCP integration.
- Added a hasScreenshot filter to global asset search: combine it with host, url, or other conditions to list only assets that currently have a screenshot.

### Improved

- Improved scheduled scans with bounded automatic retries for transient handoff failures and a surfaced last-failure summary in the management list.
- Global asset search now reports a capped match total for each query, so wide result sets show a bounded count such as 10000+ alongside token-driven pagination.

### Fixed

- Fixed overview change-metric labels so they match the rolling one-day measurement window.
- Fixed update checks failing with an invalid runtime composition evidence error after upgrading: compositions carrying artifact platforms or string-array evidence now validate correctly, restoring version display and upgrade availability.
- Fixed an internal lint regression in the MCP stop-scan tool input conversion.

### Documentation

- Documented the MCP stop-scan behavior as a maintained specification and tightened the release-notes lint gate.
- Documented the global-search screenshot filter as a maintained specification.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.197...v0.0.1-alpha.199

## 简体中文

### 新增

- 为 MCP 集成新增停止与批量停止调查扫描的工具。
- 全局资产搜索新增 hasScreenshot 筛选：可与 host、url 等条件组合，只列出当前存在截图的资产。

### 改进

- 改进定时扫描：瞬态交接失败现在会按上限自动重试，管理列表会展示最近一次失败摘要。
- 全局资产搜索现在会返回每次查询的封顶匹配总数，宽泛结果集会在分页旁显示带上限的计数（如 10000+）。

### 修复

- 修复总览变更指标标签，使其与滚动一天统计窗口保持一致。
- 修复升级后检查更新报组合证据无效错误的问题：携带 artifact platforms 或数组型 evidence 的组合资产现在可以正确校验，版本显示与升级通道恢复正常。
- 修复 MCP 停止扫描工具输入转换中的内部 lint 问题。

### 文档

- 将 MCP 停止扫描行为沉淀为维护规范，并收紧发布说明 lint 门禁。
- 将全局搜索截图筛选行为沉淀为维护规范。

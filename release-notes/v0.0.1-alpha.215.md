# v0.0.1-alpha.215

## English

### Improved

- Data source credentials and the global blacklist now live in scan configuration, beside workflows and engines. The previous settings pages for those two items are no longer available.
- Scan engine configuration now uses a compact form and YAML switch with a reset action in the header. Stage and engine rows expand in place.

### Fixed

- A manual organization scan now includes every active target. It previously kept only the newest 20 targets.
- `./uninstall.sh --purge --confirm` now deletes leftover volumes whose names match the current installation, including volumes left by an interrupted install. Ordinary uninstall still keeps existing data.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.214...v0.0.1-alpha.215

## 简体中文

### 改进

- 数据源凭据和全局黑名单现在位于扫描配置中，与工作流和引擎并列。原先设置里的这两个页面已不再提供。
- 扫描引擎配置现在在标题栏使用紧凑的表单与 YAML 切换，并带有重置操作。阶段和引擎行可以就地展开。

### 修复

- 手动发起的组织扫描现在会包含每一个活跃目标。此前只会保留最新的 20 个目标。
- `./uninstall.sh --purge --confirm` 现在会删除与当前安装名称一致的残留卷，包括中断安装留下的卷。普通卸载仍会保留已有数据。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.214...v0.0.1-alpha.215

# v0.0.1-alpha.225

## English

### Added

- Deployments with the default 3-Agent license can expand capacity with an offline signed key. When the licensed quota is exhausted, the earliest registered Agents keep claiming new tasks while over-quota Agents stay connected and finish their claimed tasks; eligibility recovers automatically after renewal or removal of earlier nodes.

### Improved

- Directory Scan now normalizes target and wordlist separators before FFUF and adds three opt-in options: target-derived variant wordlists, WAF pre-scan skipping, and result denoise filters for login redirects and backup HTML false positives.
- Vulnerability scan failures caused by missing or disabled Nuclei POC templates now show actionable guidance in the scan progress dialog, including a direct link to the POC catalog and a re-launch hint.

### Documentation

- The README and deployment guide now lead with installation, and the About dialog distinguishes between the confirmation copy and a documented manual-upgrade path for releases that declare a database migration.
- Updated the directory-scan specification to match the normalized target composition and the new opt-in options.
- The bilingual README pair is now an installation-first entry page with demo screenshots and a consolidated troubleshooting section.
- The repository home page now uses Chinese as the primary README, with English kept as a reviewed translation.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.224...v0.0.1-alpha.225

## 简体中文

### 新增

- 默认 3 个 Agent 的部署可用离线签名 Key 扩容。授权额度用尽后，最早注册的 Agent 继续领取新任务，超额 Agent 保持连接并完成已领取任务；续期或删除较早节点后会自动恢复资格。

### 改进

- Directory Scan 现在会在调用 FFUF 前规范化目标与词表分隔符，并新增三项可选能力：从目标派生的变体词表、WAF 预检跳过，以及针对登录跳转与备份 HTML 误报的结果降噪过滤。
- 由 Nuclei POC 模板缺失或未启用导致的漏洞扫描失败，现在会在扫描进度对话框中显示可执行指引，包括前往 POC 目录的直链与重新发起扫描的提示。

### 文档

- README 与部署指南现以安装为首要内容；对于声明包含数据库迁移的版本，关于对话框会区分确认文案与有文档说明的手动升级路径。
- 更新目录扫描规范，使其与规范化目标组合和新增的可选能力保持一致。
- 中英 README 现为安装优先的入口页，包含演示截图和整合后的故障排查章节。
- 仓库首页 README 现以中文为主版本，英文保留为经审核的同步翻译。

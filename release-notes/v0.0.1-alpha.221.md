# v0.0.1-alpha.221

## English

### Added

- Each published release updates the public demo (https://lunafox-demo.vercel.app). The demo shows the LunaFox interface with sample data and does not require a login. An installation continues to use the real API.
- Scan details show task runtime logs in one list, including engine output, execution errors, progress, results, status changes, stops, and session replacements. Entries stay in saved order. A failed log write does not change the task result or skip cleanup.

### Documentation

- The install guide links to the public demo before the installation steps.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.220...v0.0.1-alpha.221

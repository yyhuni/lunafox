# snapshot/application

通用规则请遵循：`server/docs/server-application-naming-template-v1.md`

snapshot 模块补充规则：

- **入口聚合**：facade 维度按业务视角划分（`facade_web_snapshot.go`、`facade_discovery_snapshot.go`、`facade_port_capture_snapshot.go`、`facade_vulnerability_snapshot.go`）。
- **Facade 边界**：facade 只保留入口委派、查询入参规整和边界错误语义映射；重复的 snapshot 边界错误映射统一收口到 `snapshot_facade_helpers.go`，不要在每个 facade 方法中复制 `errors.Is` / `dberrors.IsRecordNotFound` 分支。
- **服务编排**：`*_snapshot.go` 按资产类型拆分 query/command 服务实现，作为该模块的资源化编排文件命名，不内联端口或跨边界模型定义。
- **导出边界**：scan-scoped export/full-read 通过 facade/query service 的 domain callback（如 `ForEachByScan`）流出，不向 handler、facade 或 application port 暴露 `*sql.Rows` / `ScanRow`。
- **host-port IP 聚合列表**：`GET /v1/scans/:scan/hostPorts` 的列表响应是一行一个聚合 IP，不能返回已分页明细后再让前端聚合。application 只接受 `pageSize/pageToken/filter/orderBy`，旧 `page/sort/sortBy/sortOrder/keyword` 由 handler hard cut；`pageToken` 必须绑定 `scanId + filter + orderBy + pageSize`。filter 只允许默认搜索分支中的 `ip` / `host` 和端口 facet `port`，端口多选是 OR/IN；orderBy 只允许 `ip`、`createdAt`，默认 `createdAt desc`。聚合 `createdAt` 表示同一 IP 组内最早 `created_at`。当前 host-port 资产只保存 IPv4；IPv6 结果在 application 保存前跳过，不让混合批次里的有效 IPv4 因不支持 IPv6 而失败；materialization summary 将该跳过数与 target-scope 过滤数分开返回，不能由数据库写入数反推。
- **写入结果**：所有 snapshot command service 与 facade 仅通过 `SaveAndSync` 返回 `MaterializationSummary` 和 error。summary 明确记录输入、快照、资产、范围过滤、无效、未支持与重复计数；不得保留二元 count 返回值或 `SaveAndSyncWithSummary` 兼容方法。调用方收到 error 时不得将非空 summary 视为成功。result-ingest command 路径的 scan/target lookup、snapshot write 和 asset sync 必须贯穿同一个非 nil caller context，不能在前置 lookup 换成 `context.Background` 或裸 DB；该路径由 `result-ingest` 的最终执行栅栏事务统一包裹，Endpoint 不再是部分提交例外。
- **最新有效观测**：先完成身份、格式、核心产物和 scope 校验，再按资源自己的持久化自然键保留请求顺序中最后一个有效项；Snapshot 与 Asset 必须从同一个 winner 构建。Website v1 是完整观测，accepted 记录的 omitted optional 字段按零值清空旧字段；Screenshot 的 `image` 是核心产物，缺失、空或不可验证时不得参与 winner 选择。
- **观测 URL**：Website、Endpoint、Directory、Screenshot 和 Vulnerability Snapshot 的 URL 是原始证据；准入后的字符串不 trim、不解析重建、不百分号解码，URL 自然键和普通筛选均精确比较。Host/Target 校验只使用临时派生值，不能替换 URL。
- **Screenshot 准入**：result-ingest 已在 `contracts/results` 完成 closed item、原始观测 URL、statusCode 和 standard-base64 校验；本模块的持久化边界再次只接受结构有效 WebP，宽度不超过 800px、像素不超过 8,000,000、编码字节不超过 256 KiB。Server 原样保存 WebP，不缩放、不转码、不把 PNG/JPEG/AVIF 作为历史兼容格式，也不新增人工 Screenshot 上传兼容层。
- **原子物化**：所有 result-ingest 类型均由最终执行栅栏在同库事务内依次写入 Snapshot（如适用）、Asset 和 Scan summary（如适用）；任一栅栏、写入或 summary 失败都必须回滚该批次。协调器只处理数据库；日志、消息和其他外部副作用只能在提交成功后执行。
- **website snapshot 列表**：`GET /v1/scans/:scan/websites` 是已迁移的后端分页业务列表。application 只接受 `pageSize/pageToken/filter/orderBy`，旧 `page/sort/sortBy/sortOrder/keyword` 由 handler hard cut；`pageToken` 必须绑定 `scanId + filter + orderBy + pageSize`。filter 外部字段只允许 lowerCamelCase 的 `url/statusCode/tech/webserver/contentType/vhost`；普通 URL 文本和 `url` 条件均是精确原始字符串匹配，`tech` 多选是数组重叠语义，`vhost` 是布尔语义。orderBy 只允许 `statusCode/contentLength/createdAt`，默认 `createdAt desc`；不得开放 `url` 排序；`statusCode/contentLength` 排序的空值固定 `NULLS LAST`。不得接受 `status_code/content_length/content_type/created_at` 这类数据库 snake_case 字段作为外部 filter/orderBy。
- **endpoint URL snapshot 列表**：`GET /v1/scans/:scan/endpoints` 是已迁移的后端分页业务列表。application 只接受 `pageSize/pageToken/filter/orderBy`，旧 `page/sort/sortBy/sortOrder/keyword` 由 handler hard cut；`pageToken` 必须绑定 `scanId + filter + orderBy + pageSize`。filter 外部字段只允许 lowerCamelCase 的 `url/statusCode/tech/webserver/contentType/vhost`；普通 URL 文本和 `url` 条件均是精确原始字符串匹配，`tech` 多选是数组重叠语义，`vhost` 是布尔语义。orderBy 只允许 `statusCode/contentLength/createdAt`，默认 `createdAt desc`；`statusCode/contentLength` 排序的空值固定 `NULLS LAST`。不得开放 `url` 排序，也不得接受 `status_code/content_length/content_type/created_at` 这类数据库 snake_case 字段作为外部 filter/orderBy。
- **directory snapshot 列表**：`GET /v1/scans/:scan/directories` 是已迁移的后端分页业务列表。application 只接受 `pageSize/pageToken/filter/orderBy`，旧 `page/sort/sortBy/sortOrder/keyword` 由 handler hard cut；`pageToken` 必须绑定 `scanId + filter + orderBy + pageSize`。filter 外部字段只允许 `url/status/contentType`；普通 URL 文本和 `url` 条件均是精确原始字符串匹配，同一 facet 多值是 OR/IN，不同 facet 与搜索是 AND。orderBy 只允许 `status/contentLength/createdAt`，默认 `createdAt desc`；`status/contentLength` 排序空值固定 `NULLS LAST`。不得开放 `url/contentType` 排序，也不得接受 `content_length/content_type/created_at` 这类数据库 snake_case 字段作为外部 filter/orderBy。
- **screenshot snapshot 列表**：`GET /v1/scans/:scan/screenshots` 是已迁移的后端分页图库列表。application 只接受 `pageSize/pageToken/filter/orderBy`，旧 `page/sort/sortBy/sortOrder/keyword` 由 handler hard cut；`pageToken` 必须绑定 `scanId + filter + orderBy + pageSize`。filter 外部字段只允许 `url/statusCode`；普通 URL 文本和 `url` 条件均是精确原始字符串匹配，`statusCode` 多选是 OR/IN，与 URL 搜索是 AND。orderBy 只允许 `statusCode/createdAt`，默认 `createdAt desc`；`statusCode` 排序空值固定 `NULLS LAST`。不得开放 `url/image/updatedAt` 排序，也不得接受 `status_code/created_at` 这类数据库 snake_case 字段作为外部 filter/orderBy；列表响应不得选择或返回 `image` blob，图片只走专用 blob endpoint。
- **vulnerability snapshot 列表**：`GET /v1/scans/:scan/vulnerabilities` 是已迁移的后端分页业务列表。application 只接受 `pageSize/pageToken/filter/orderBy`，旧 `page/sort/sortBy/sortOrder/keyword/severity/isReviewed` 由 handler hard cut；`pageToken` 必须绑定 `scanId + filter + orderBy + pageSize`。filter 外部字段只允许 `url/severity/source/vulnType`；普通 URL 文本和 `url` 条件均是精确原始字符串匹配，同一 facet 多值是 OR/IN，不同 facet 与搜索是 AND。scan snapshot 没有审查状态字段，必须拒绝 `isReviewed` filter，不得模拟审查 tab。orderBy 只允许 `createdAt`，默认 `createdAt desc`；不得开放 URL、severity、source、vulnType、cvssScore 排序，也不得接受 `vuln_type/created_at` 这类数据库 snake_case 字段作为外部 filter/orderBy。
- **adapter 例外**：当前无 transport-facing 或 cross-module bridge 型 adapter service 例外。
- **端口拆分**：端口按资源+职责拆分为 `*_query_ports.go`、`*_command_ports.go`、`*_lookup_ports.go`、`*_codec_ports.go`。
- **模型命名**：跨边界模型和入参分别使用 `*_item_models.go`、`*_query_inputs.go`（如 `snapshot_list_query_inputs.go`、`vulnerability_snapshot_query_inputs.go`），domain 别名使用 `*_aliases.go`。
- **历史迁移**：无历史聚合文件，保持资源化命名不回退。
